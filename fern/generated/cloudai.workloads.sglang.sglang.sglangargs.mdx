### `SglangArgs`

Base command arguments for SGLang instances.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| <Anchor id="cloudai.workloads.sglang.sglang.SglangArgs.gpu_ids" />`gpu_ids` | `str \| list[str] \| None` | `None` | Comma-separated GPU IDs. If not set, all available GPUs will be used. |
| <Anchor id="cloudai.workloads.sglang.sglang.SglangArgs.num_nodes" />`num_nodes` | `int \| list[int] \| None` | `None` | Number of Slurm nodes assigned to this role in disaggregated serving mode. |
| <Anchor id="cloudai.workloads.sglang.sglang.SglangArgs.disaggregation_transfer_backend" />`disaggregation_transfer_backend` | `str \| list[str] \| None` | `'nixl'` | Transfer backend used in disaggregated mode. It is consumed by command generation and not emitted as a generic serve argument. |
