## Choose a setup path

- [Run on Slurm](/guides/slurm): submit workloads to compute nodes from a login or submit host.
- [Run your first experiment](/tutorial): run a local storage experiment with Standalone.
- [Run on Kubernetes](/guides/kubernetes): run Dynamo or NCCL with the appropriate Kubernetes operators.

RunAI currently has an NCCL integration; use [Set up RunAI](/guides/runai) for its configuration.
LSF currently has a Sleep integration for scheduling checks; its fields are under [lsf system](/systems#lsf-system).
