This legacy integration is deprecated. Use [Nemo Run](/workloads/nemo-run) for NeMo training and fine-tuning,
or [MegatronBridge](/workloads/megatron-bridge) for a maintained training starter.

<Anchor id="migrate-an-experiment" />

## Migrate an experiment

Choose the matching model and training recipe in the replacement workload. Transfer dataset and tokenizer paths,
parallelism, and batch settings deliberately; the launcher's configuration is not interchangeable with the new recipe.
Run a short case and compare its output before scaling up.

<Anchor id="dataset-preparation" />

## Dataset preparation

Provision the selected recipe's data on storage accessible to the execution nodes. Use that recipe's documented
format and tokenizer, then configure paths and mounts. See [Prepare model weights](/guides/model-access) and [Set up your execution environment](/guides/environment).
