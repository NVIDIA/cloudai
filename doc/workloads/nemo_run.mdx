This workload (`test_template_name` is `NemoRun`) executes NeMo training and fine-tuning tasks using the NeMo Run framework.

<Anchor id="usage-examples" />

## Usage Examples

Test TOML example:

``` toml
name = "my_nemo_test"
description = "Example NeMo Run test"
test_template_name = "NemoRun"

[cmd_args]
recipe = "llama3_8b"
task = "pretrain"
```

Test Scenario example:

``` toml
name = "nemo-run-test"

[[Tests]]
id = "nemo.1"
num_nodes = 4
time_limit = "02:00:00"

test_name = "my_nemo_test"
```

Test-in-Scenario example:

``` toml
name = "nemo-run-test"

[[Tests]]
id = "nemo.1"
num_nodes = 4
time_limit = "02:00:00"

name = "my_nemo_test"
description = "Example NeMo Run test"
test_template_name = "NemoRun"

  [Tests.cmd_args]
  recipe = "llama3_8b"
  task = "pretrain"
```
