## Adding New Workloads

To add documentation for a new workload:

1.  Add docstrings to your Python classes and methods.
2.  Create an MDX file in `doc/workloads/` (e.g., `my_workload.mdx`).
3.  Add it to the table above and to `fern/docs.yml`.
4.  Add its reference classes to `fern/reference.yml` and include the generated snippets using Fern's `Markdown` component, with `src` set to `/generated/fully.qualified.Class.mdx`.

The documentation will be automatically generated during the build process.
