<Anchor id="run-your-first-experiment" />

Run a small file I/O experiment locally and find its results. This path needs no GPU or scheduler.

<Steps>

<Step title="Prepare">

[Install CloudAI](/getting-started) and run the following commands from the repository root.
Install the Fio executable; on Ubuntu, use `sudo apt-get install fio`.

```bash
cp conf/common/system/standalone_system.toml standalone.toml
```

</Step>

<Step title="Run">

The example writes an 80 MiB file at `/tmp/cloudai-fio-quickstart`. Choose another filename in the scenario
if you want to measure a different filesystem.

```bash
uv run cloudai run --system-config standalone.toml \
    --test-scenario conf/experimental/quickstart/fio.toml
```

<Accordion title="View the scenario">

```toml
name = "quickstart-fio"

[[Tests]]
id = "fio"
name = "fio"
description = "Small file I/O benchmark"
test_template_name = "Fio"
num_nodes = 1
time_limit = "00:05:00"

  [Tests.cmd_args]
  fio_binary = "fio"

    [Tests.cmd_args.args]
    name = "cloudai-quickstart"
    filename = "/tmp/cloudai-fio-quickstart"
    rw = "randwrite"
    bs = "128k"
    size = "80m"
    iodepth = 1
    numjobs = 1
    group_reporting = true
    thread = true
```

</Accordion>

</Step>

<Step title="Inspect">

Open the results directory printed by CloudAI. Inspect `experiment.json` for execution status and recorded metrics,
then the workload output for bandwidth and IOPS. A successful process alone does not establish that you measured
the intended device: check the configured path, I/O pattern, block size, and file size.
See [Read results and generate reports](/reporting) for result interpretation.

</Step>

<Step title="Adapt">

Change one Fio setting at a time and compare results under the same conditions.
Use [Understand experiment configuration](/guides/configuration) to understand the two configuration files.
For GPU or multi-node experiments, choose a workload from [Workloads](/workloads/index) and follow
[Set up your execution environment](/guides/environment). For configuration search, continue to [Run a configuration search](/optimization/search).

</Step>

</Steps>
