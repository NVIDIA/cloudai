<Anchor id="extend-cloudai" />

Add the workload, metrics, search policy, or execution backend your investigation needs.
Use CloudAI's public interfaces and registry to integrate your own tools and environments.

For an existing script or container, start with [Bash Command](/workloads/bash-cmd) or [Slurm Container](/workloads/slurm-container) on Slurm.
For a new integration, choose an extension guide below. Extensions useful to others are welcome as [contributions](/extend/contribute).
