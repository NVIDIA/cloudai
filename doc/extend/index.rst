Extend CloudAI
==============

Add the workload, metrics, search policy, or execution backend your investigation needs.
Use CloudAI's public interfaces and registry to integrate your own tools and environments.

For an existing script or container, start with :doc:`/workloads/bash_cmd` or :doc:`/workloads/slurm_container` on Slurm.
For a new integration, choose an extension guide below. Extensions useful to others are welcome as :doc:`contributions <contribute>`.
